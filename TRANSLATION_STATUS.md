# CLUBB Fortran → JAX translation status

Generated by walking `clubb_release/src/**.F90` (the Fortran oracle) and `clubb_jax/src/**.py` (the JAX port) and mapping each Fortran source to its JAX counterpart. The naming mirror is 1:1 where it can be (`clubb_jax/src/CLUBB_core/x.py` ↔ `clubb_release/src/CLUBB_core/x.F90`), but much Fortran is **folded** into a differently-named JAX module (the benchmark cases all run through `generic_forcings.py`; `stats_netcdf.F90` → `io/stats_writer.py`; solver/PDF helpers are inlined; the BUGSrad LW/SW routines are split into more files), so a raw filename match undercounts the port.

**Legend:** ✅ translated (1:1 mirror) · 🔁 ported but folded into a differently-named JAX module · ➖ not a translation target (LAPACK/Numerical-Recipes libs, Fortran build/IO/test infra, SILHS RNG, or an alternative scheme the gated config never uses) · ❌ genuinely unported physics (a potential future target).

> Caveat: this is a static filename/functionality map maintained by inspection; the 🔁 "folded" target is the principal JAX home, not necessarily the only one. "Ported" here means *translated into JAX*, which is distinct from *bit-faithful* — see DESIGN.md "Cross-case bit-faithfulness status" for the latter.

Counts refreshed at the completeness-loop iter 102 (the original loop's last summary, ~Iter313, predated the iters 81-102 sweep: all alternative PDF closures + `new_hybrid_pdf_main` + `remapping_module` (both methods) moved to ✅, and the CGILS init/radiation/forcing path was added). Excluding the 64 not-a-target files, 128 of the 138 in-scope files are ported and 10 remain. The genuinely-remaining unported set is **no-oracle / impractical subsystems**: COAMPS microphysics (Fortran fatal-errors → no oracle), the GFDL `aer_ccn_act_wpdf_k` 5-D single-precision lookup, the SCM aerosol-activation subsystem, `pdf_hydromet_microphys_wrapper` (zero validated payoff — its outputs are 0 for every gated case), and a few benchmark cases that need those subsystems or SILHS. The clex9 altocumulus cases run through the generic Morrison path and are bit-faithful gate members.
